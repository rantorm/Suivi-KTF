# Kanton'ny Fanantenana — Pilotage

Application PWA de pilotage des activités de la chorale **Kanton'ny Fanantenana**.

## 5 pôles (figés)
- Admin
- Communication
- Hetsika sy Fitoriana
- Logistique
- Hira sy Mozika

## Fonctionnalités
- **Accueil** : KPIs globaux, alertes, événements proches, actions prioritaires
- **Événements** : campagnes avec dashboard dédié (compte à rebours J-XX)
- **Planning global** : calendrier unique + toutes les activités
- **Pôles** : vue par pôle (propriétaire / concerné)
- **Responsables** : petite liste éditable, attribution aux actions
- Export / Import JSON, 100 % local, installable en PWA

## Déploiement
Publier le dossier sur un hébergement HTTPS (GitHub Pages, Netlify…).
